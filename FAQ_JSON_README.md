# FAQ Система с JSON Переводами

Обновленная система FAQ, использующая JSON поля для переводов вместо отдельных таблиц переводов, как в других ресурсах проекта.

## 🎯 Что изменилось

### **Было (старая система):**
- Отдельная таблица `faq_translations`
- Модель `FaqTranslation`
- Связи через `language_id`

### **Стало (новая система):**
- JSON поля `question` и `answer` в таблице `faqs`
- Использование `spatie/laravel-translatable`
- Единая модель `Faq`

## 🏗️ Структура данных

### Таблица `faqs`:
```sql
CREATE TABLE faqs (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    order INT DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    question JSON NOT NULL,
    answer JSON NOT NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);
```

### JSON структура:
```json
{
    "question": {
        "uk": "Як працює система?",
        "en": "How does the system work?",
        "ru": "Как работает система?"
    },
    "answer": {
        "uk": "Система працює наступним чином...",
        "en": "The system works as follows...",
        "ru": "Система работает следующим образом..."
    }
}
```

## 📝 Использование в Nova

### Создание FAQ:
1. Перейдите в Nova → FAQ
2. Заполните поля для каждого языка:
   - **Вопрос (Українська)** - `question->uk`
   - **Вопрос (English)** - `question->en`
   - **Вопрос (Русский)** - `question->ru`
   - **Ответ (Українська)** - `answer->uk`
   - **Ответ (English)** - `answer->en`
   - **Ответ (Русский)** - `answer->ru`
3. Укажите порядок и активность
4. Сохраните

## 🌐 Веб-страница

### Маршрут: `GET /faq`

FAQ отображается как обычная веб-страница с серверным рендерингом:
- Автоматически использует текущий язык сайта
- Интегрируется с существующей темой (светлая/темная)
- Включает breadcrumbs навигацию
- Поддерживает все стили сайта

## 🎨 Стили

### Основные классы:
- `.faq-accordion` - контейнер
- `.faq-item` - элемент FAQ
- `.faq-question` - вопрос (кликабельный)
- `.faq-answer` - ответ (скрытый/показанный)
- `.faq-toggle` - иконка переключения

### Мобильные стили:
- `touch-action: pan-y` - предотвращает горизонтальные свайпы
- `user-select: none` - запрещает выделение текста
- `-webkit-tap-highlight-color: transparent` - убирает подсветку тапа
- Адаптивные размеры для мобильных устройств
